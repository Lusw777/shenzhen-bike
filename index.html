深圳共享单车骑行时空分析与需求预测平台

本科毕业设计项目 · 城市交通大数据方向
数据清洗 时空可视化 片区聚类 需求预测 智能问答

项目简介

本项目面向城市共享单车运营中的数据分析需求，基于深圳市政府数据开放平台提供的共享单车企业每日订单数据， 构建覆盖「数据接入—清洗治理—时空分析—模型实验—知识问答」的完整平台。

系统分为离线数据分析流水线与在线 Web 服务两部分：离线侧完成数据获取、清洗、特征派生与知识库构建； 在线侧提供六类功能页面，支持行政区级热力分布、时段与工作日/周末对比、OD 流向、片区聚类、异常骑行识别、 区域骑行需求预测以及基于检索增强的智能问答。

数据来源与合规说明

数据提供方 深圳市政府数据开放平台（opendata.sz.gov.cn）
数据集名称 共享单车企业每日订单表（数据集编号 29200_00403627）
数据内容 用户 ID、企业 ID、起止时间、起止经纬度
使用方式 通过平台开放接口按时间范围分页获取，仅用于本科毕业设计中的学术研究与技术验证
数据已由数据提供方进行脱敏处理。本项目不存储、不展示任何可直接识别个人身份的信息， 不用于商业用途；地图展示所使用的地理边界数据仅用于可视化呈现。

系统功能模块

  • 数据管理：原始数据导入、增量与覆盖导入、清洗流水线与清洗报告、筛选预览与条件导出。
  • 可视化分析：订单总量与均值指标、行政区热力、日/周时序、小时高峰曲线、天气对比、时长与距离分布、OD 流向。
  • 时空挖掘：片区 K-Means 聚类与肘部法则选 K、孤立森林异常骑行识别。
  • 需求预测：按行政区训练 LSTM 与 ARIMA，预测未来 14 天订单量，输出 RMSE / MAE / R² 对比。
  • 智能问答：基于系统内统计结论与模型指标构建知识库，检索增强回答并标注来源，低于阈值时拒答。
  • 系统管理：账号登录与角色区分、操作日志、异步训练任务状态、接口文档。

文档Swagger / OpenAPI 自动生成接口文档

研究目标

  • 建立可复现的共享单车订单数据清洗与特征派生流程；
  • 量化呈现骑行需求的时空分布特征与片区差异；
  • 对比时序模型在区域订单量预测上的表现并给出评估指标；
  • 验证检索增强问答在结构化统计数据上的可用性与拒答机制。
